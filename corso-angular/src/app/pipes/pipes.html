Cosa sono le pipe

Una pipe trasforma un valore solo nel template. Il dato nel componente resta com'è. Si scrive {{ '{' }}{{ '{' }} valore | nomePipe {{ '}' }}{{ '}' }}. Dopo il nome si possono passare parametri, separati da due punti. In un componente standalone la classe della pipe va nell'array imports.

Testo

uppercase mette tutto in maiuscolo: {{ 'testo da trasformare' | uppercase }}

lowercase mette tutto in minuscolo: {{ 'testo da trasformare' | lowercase }}

titlecase mette la maiuscola all'inizio di ogni parola: {{ 'testo da trasformare' | titlecase }}

slice:0:5 prende i caratteri dall'indice 0 fino al 5, escluso: {{ 'testo da trasformare' | slice:0:5 }}

slice:5 prende i caratteri dall'indice 5 fino alla fine: {{ 'testo da trasformare' | slice:5 }}

Data, numero, percentuale, valuta

date (DatePipe) formatta una data. Il parametro può essere uno schema (dd giorno, MM mese, yyyy anno, HH ore, mm minuti) oppure un nome già pronto. schema: {{ oggi | date:'dd/MM/yyyy HH:mm' }}

short: data e ora brevi. {{ oggi | date:'short' }}

medium: data e ora medie. {{ oggi | date:'medium' }}

long: data e ora lunghe. {{ oggi | date:'long' }}

full: data e ora complete. {{ oggi | date:'full' }}

shortDate: solo la data, breve. {{ oggi | date:'shortDate' }}

mediumDate: solo la data, media. {{ oggi | date:'mediumDate' }}

longDate: solo la data, lunga. {{ oggi | date:'longDate' }}

fullDate: solo la data, completa. {{ oggi | date:'fullDate' }}

shortTime: solo l'ora, breve. {{ oggi | date:'shortTime' }}

mediumTime: solo l'ora, con i secondi. {{ oggi | date:'mediumTime' }}

longTime: ora e fuso. {{ oggi | date:'longTime' }}

fullTime: ora, secondi e fuso per esteso. {{ oggi | date:'fullTime' }}

number (DecimalPipe) formatta un numero. '1.2-2' significa almeno 1 cifra intera e da 2 a 2 decimali. {{ importo | number:'1.2-2' }}

percent (PercentPipe) moltiplica il valore per 100 e aggiunge il simbolo %. quota vale 0.25, quindi diventa 25%. '1.0-0' significa niente decimali. {{ quota | percent:'1.0-0' }}

currency (CurrencyPipe) formatta una somma. I parametri sono, in ordine: codice valuta (EUR), come mostrarla (symbol), i decimali (1.2-2) e la lingua (it). {{ importo | currency:'EUR':'symbol':'1.2-2':'it' }}

Frasi in base al valore

Queste due pipe non caricano un file di lingua. Nel componente c'è una mappa: a ogni valore corrisponde una frase già scritta. La pipe sceglie quale mostrare. La chiave other è il caso di riserva, quando il valore non è tra gli altri.

i18nSelect (I18nSelectPipe) cerca il valore nella mappa. genere vale 'donna', quindi mostra la frase di quella chiave. {{ genere | i18nSelect:frasiGenere }}

i18nPlural (I18nPluralPipe) sceglie la frase in base a un numero. =0 e =1 sono i casi esatti. other vale per tutti gli altri numeri. Il carattere # nella frase viene sostituito dal numero. quantita vale 1, quindi: {{ quantita | i18nPlural:frasiQuantita }}
